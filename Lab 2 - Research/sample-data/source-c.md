# Vendor C — Document Management Platform

> Used in Lab 2, Exercise 2. Fictional vendor profile for lab purposes only.

**Vendor:** DocuNest
**Deployment:** On-premise or private cloud; no shared SaaS offering
**Pricing model:** Perpetual license plus annual maintenance fee

---

## Key Features

- Full-text search across all document content (including PDFs and scanned documents via OCR)
- Highly configurable access control model with custom role definitions
- Comprehensive audit trail including document views, not just edits
- Native Microsoft 365 deep integration (documents open and save directly in Office apps)
- No third-party connectors required for core Microsoft workflows
- Workflow automation for approvals and routing

## Security and Compliance

- SOC 2 Type II certified
- ISO 27001 certified
- Fully air-gapped deployment option available for high-security environments
- Data never leaves customer-controlled infrastructure
- MFA and SSO supported via Active Directory integration

## Ease of Adoption

- Rated 3.6/5 on G2 for ease of use (based on 95 reviews)
- Implementation typically requires 6–10 weeks including IT setup and configuration
- Dedicated implementation team included in license fee
- Steeper learning curve reported by end users; training program required

## Known Limitations

- No cloud or mobile-only option; requires on-premise infrastructure investment
- Upfront license cost significantly higher than SaaS alternatives
- Slower to release new features compared to cloud-native competitors
- Mobile experience limited; full functionality requires desktop client
- Implementation timeline longer than SaaS options

## Pricing (indicative)

- Perpetual license: $85,000–$150,000 depending on user count
- Annual maintenance: 20% of license fee
- Implementation services: $25,000–$40,000 (one-time)
