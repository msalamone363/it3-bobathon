# Vendor B — Document Management Platform

> Used in Lab 2, Exercise 2. Fictional vendor profile for lab purposes only.

**Vendor:** Filevault Pro
**Deployment:** Cloud-hosted only (no on-premise option)
**Pricing model:** Per-user, annual subscription (monthly billing available at 15% premium)

---

## Key Features

- Document storage with folder hierarchy and tagging
- Basic access controls (owner, editor, viewer roles per document)
- Version history with unlimited revisions
- Microsoft 365 integration available via API; requires IT configuration
- Google Workspace integration native and plug-and-play
- Built-in eSignature (no additional cost)
- Offline access via desktop sync client

## Security and Compliance

- SOC 2 Type I certified (Type II audit in progress, expected Q1 next year)
- Data encrypted at rest and in transit
- SSO supported via OAuth 2.0 and SAML 2.0
- Audit logging available on Business tier and above; not included on Starter tier

## Ease of Adoption

- Rated 4.4/5 on G2 for ease of use (based on 210 reviews)
- Most users report being productive within a few hours of onboarding
- No dedicated customer success manager; support via shared ticket queue
- Active user community and documentation library

## Known Limitations

- Microsoft 365 integration requires IT involvement and typically takes 1–2 weeks to configure
- Audit log detail is limited; does not log individual document views, only edits and shares
- No US-only data residency option; data stored in multi-region EU/US infrastructure
- Compliance certifications not yet at SOC 2 Type II level

## Pricing (indicative)

- Starter: $8/user/month (limited audit logging, no SSO)
- Business: $14/user/month (full audit logging, SSO, offline sync)
- Enterprise: custom pricing (dedicated infrastructure, SLA guarantees)
