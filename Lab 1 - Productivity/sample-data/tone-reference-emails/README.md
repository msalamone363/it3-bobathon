# Tone Reference Emails (Optional)

This folder is for Exercise 3 of Lab 1 — drafting an email in *your own* writing voice.

## What to add

Add **3–6 emails you've actually written** as separate `.md` or `.txt` files in this folder
(e.g. `email-1.md`, `email-2.md`, ...). Good candidates:
- A status update you sent to your manager or team
- A follow-up email to a vendor, client, or colleague
- Any routine email that reflects how you normally write

You do not need a large sample — 3–6 short emails is enough for Bob to pick up on tone,
sentence length, greeting/sign-off style, and level of formality.

## What NOT to add

- Anything confidential, sensitive, or that you wouldn't want visible in a shared lab environment
- Emails containing customer data, credentials, or internal-only information

> **Privacy note:** These emails are used only to describe *how* you write — not *what* you wrote
> about. If in doubt, redact specifics (names, numbers, account details) before adding a file here,
> or simply skip this exercise. Delete these files after the lab if you'd prefer not to leave them
> in place.

## If you skip this

Exercise 3 still works without any files in this folder — Bob will fall back to a neutral,
professional tone instead of your personal voice. This folder is entirely optional.
